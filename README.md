# Chess and Graph Theory Report

**Modelling Strategy with Minimax and Game Trees**

An academic report completed for **INFR-1010U — Discrete Mathematics** at Ontario Tech University.

## Overview

This report explores how discrete mathematics supports decision-making in chess. It examines graph representations, game trees, search algorithms, and move evaluation, connecting these concepts to a Python chess engine.

The report accompanies my AI Chess Engine project and focuses on its mathematical foundations.

## Topics Covered

- **Graph theory:** Representing chess-piece movement using vertices and edges.
- **Game trees:** Representing board states as nodes and legal moves as edges.
- **Depth-First Search and Breadth-First Search:** Comparing approaches to exploring graphs and trees.
- **Minimax:** Evaluating possible moves and an opponent’s responses.
- **Alpha-beta pruning:** Skipping branches that cannot affect the Minimax result.
- **Knight’s Tour:** Examining a Hamiltonian path problem involving legal knight moves.
- **Material-based evaluation:** Assigning piece values to assess board positions.

## Connection to the Chess Engine

The practical application uses Python and the python-chess library to explore legal moves and evaluate board states.

The report discusses depth-limited Minimax search with alpha-beta pruning and a material-based evaluation function. BFS and the Knight’s Tour are discussed as theoretical topics, rather than claimed as implemented engine features.
